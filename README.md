# Professional Portfolio (React Version)

This is the repository for my professional portfolio website, rebuilt using **React**, **Vite**, and **Vanilla CSS**.

🌐 **Hosted at**: [ganwild.pw](https://ganwild.pw)

## 🛠️ Tech Stack
*   **React** (v18+)
*   **Vite** (Asset Bundling)
*   **React Router Dom** (SPA Routing)
*   **Vanilla CSS** (Responsive Styling)
*   **Remixicon** (Icons)
*   **Docker & Nginx** (Containerized Production Server)
